# ศูนย์ข่าวสาร

เว็บไซต์ข่าวภาษาไทยแบบหน้าเดียว ออกแบบให้ใช้งานได้ทั้งบนมือถือ แท็บเล็ต และคอมพิวเตอร์

## ความสามารถ

- แสดงข่าวเด่น ข่าวประกาศสำคัญ และรายการข่าว
- ค้นหาข่าวแบบทันทีจากทั้งหัวข้อและเนื้อหาสรุป พร้อมเน้นคำค้นหาในหัวข้อ
- ดาวน์โหลดข่าวแต่ละรายการเป็น PDF โดยรองรับการแสดงผลภาษาไทย
- เมนู hamburger สำหรับหน้าจอมือถือ
- ปรับการจัดวางการ์ดข่าวตามขนาดหน้าจอ

## วิธีเปิดใช้งาน

1. ดาวน์โหลดไฟล์โปรเจกต์ทั้งหมด
2. เปิด `index.html` ด้วยเว็บเบราว์เซอร์ เช่น Chrome, Edge หรือ Firefox
3. การค้นหาและการแสดงหน้าเว็บทำงานได้ทันที ส่วนการดาวน์โหลด PDF และฟอนต์ภาษาไทยใช้ไลบรารีและฟอนต์จาก CDN จึงต้องเชื่อมต่ออินเทอร์เน็ต

หากใช้ VS Code สามารถติดตั้งส่วนขยาย Live Server แล้วคลิกขวาที่ `index.html` เลือก **Open with Live Server** เพื่อเปิดเว็บผ่านเซิร์ฟเวอร์ภายในเครื่อง

## เทคโนโลยี

- HTML5
- CSS3
- JavaScript (Vanilla ES6)
- jsPDF และ html2canvas สำหรับสร้างไฟล์ PDF
- Noto Sans Thai สำหรับแสดงผลภาษาไทยใน PDF
